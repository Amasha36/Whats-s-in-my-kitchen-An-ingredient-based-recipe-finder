# Food artwork

Recipe cards and details now use 52 distinct dish illustrations in `recipes-01.png` through `recipes-07.png`, mapped by recipe ID and name. See [recipe-image-prompts.md](recipe-image-prompts.md) for exact prompts and provenance. The category atlas below is retained only for decorative home, splash and settings artwork.

`food-atlas.png` is original AI-generated category inspiration artwork created with the built-in image generation tool. It is bundled locally, with no runtime image downloads. The 1536 x 1024 atlas contains six square category tiles in dataset order: Breakfast, Lunch, Dinner, Snacks, Desserts, Drinks. Images represent categories rather than exact photographs of all 52 recipes.

## Generation prompt

Use case: photorealistic-natural. Asset type: bundled food photography atlas for a mobile recipe app. Create one landscape image in a precise 3 column by 2 row grid of six equal square photographs, no gaps, no borders, no text, no labels. Every tile has its own soft pastel background, overhead food photography, beautifully styled but natural. Top left: golden pancakes with banana slices and a few berries on a cream plate, apricot background. Top middle: Sri Lankan rice and colorful vegetable curry bowl, mint background. Top right: tomato pasta with basil on a ceramic plate, pale lavender background. Bottom left: golden vegetable toast triangles and crunchy vegetable fritters, peach background. Bottom middle: chocolate dessert and strawberries in a small bowl, pastel pink background. Bottom right: iced lime drink with mint and citrus, pastel turquoise background. Keep each food subject centered with generous margins, all props fully within own tile; no objects crossing tile boundaries. Editorial food photography with soft daylight, vivid appetizing colors, realistic textures. Landscape aspect ratio 3:2. This is category inspiration artwork, not a screenshot or UI.
